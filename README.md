# CODTECH Task 3: Graph Data Analysis (Social)

## Project Overview
This project analyzes a social network using graph theory and Python. It visualizes connections between users and identifies highly connected users.

## Objective
To understand relationships and connections in a social network using graph analysis techniques.

## Technologies Used
- Python
- NetworkX
- Matplotlib
- Google Colab

## Dataset
The project uses the Karate Club social network dataset available in NetworkX.

## Methodology
1. Create a social network graph.
2. Visualize users and their connections.
3. Calculate degree centrality.
4. Identify the top five most connected users.
5. Analyze network density, average degree, and connected components.

## Results
The project generates a social network visualization and displays network statistics and the most connected users.

## Conclusion
Graph analysis helps understand social relationships, network structure, and influential users.

## How to Run
1. Open the notebook in Google Colab.
2. Run all code cells in order.
3. View the graph and analysis results.
